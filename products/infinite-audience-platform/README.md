# Infinite Audience Platform API

Build with the same identity and audience capabilities that power the Infinite
Audience platform. Use the API to resolve and enrich customer records, compose
audiences, connect destinations, and bring Infinite Audience into your existing
workflows.

## Start here

- [Explore the API reference](https://docs.infiniteaudience.ai/api/)
- [Read the how-to guides](https://docs.infiniteaudience.ai/)
- [Download the OpenAPI YAML](openapi.yaml)
- [Download the OpenAPI JSON](openapi.json)

The OpenAPI files in this directory are generated from the customer-facing
production contract after a successful documentation deployment. They are
provided for tools such as Postman, Insomnia, code generators, and AI-assisted
development.

> **Generated files:** Please do not edit the OpenAPI files here directly.
> Report an issue in this repository or use the support options in the
> [documentation](https://docs.infiniteaudience.ai/). Approved fixes are made
> in the platform source and arrive here through an automated pull request.
